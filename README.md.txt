# Computer Networks Laboratory

This repository contains the practical experiments
performed as part of the CSBB 301 Computer Networks
Laboratory.

## Experiments

1. Network Cables and Crimping
2. Basic Network Commands
3. Network Devices
4. IP Addressing
5. Local Area Network (LAN)
6. Router Configuration
7. Peer-to-Peer Networking
8. Network Address Translation (NAT)
9. Routing Protocols
10. TCP and UDP Client-Server Applications
11. Socket Programming
12. Network Tools Exploration
13. Dynamic Host Configuration Protocol (DHCP)

Each experiment folder contains its documentation
and relevant Packet Tracer file, where applicable.
